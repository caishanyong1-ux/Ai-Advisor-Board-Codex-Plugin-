# AI Advisory Board 1.3.3

A local Codex plugin for user-approved multi-model deliberation, anonymous peer review, and persistent meeting records.

[Download the public package](ai-advisory-board-1.3.3-public.zip?raw=true) · [SHA-256 checksum](SHA256SUMS) · [Security and privacy review](../../SECURITY-REVIEW.md)

Version 1.3.3 adds conversation-scoped presentation language, built-in English/Simplified Chinese/Traditional Chinese interfaces, and validated templates for additional languages. Internal discussion remains American English; formal outputs follow the approved task language.

Requires macOS, Python 3.9+, and Codex desktop with the `codex` CLI. Extract the package, then run `python3 install.py` from its directory. Connect your own model providers and approve each meeting before paid work begins.

The source and package use the MIT License, with upstream notices preserved. The release passed 211 isolated tests and the documented package review. No credentials or meeting data are included.
